# Evaluation evidence

Dated files under `docs/evaluation/` are dissertation evidence. They are not
the setup path. Install the database with Flyway; see
[DATABASE_HANDOVER.md](../DATABASE_HANDOVER.md).

| Kind | Examples | Use as |
| --- | --- | --- |
| Current testing instructions | [TESTING_CHECKLIST.md](../TESTING_CHECKLIST.md), [END_TO_END_VALIDATION.md](../END_TO_END_VALIDATION.md) | What to run or observe now |
| Dated automated evidence | `FINAL_EVIDENCE_2026-09-17.md`, `recommendation-evaluation-results.*`, `performance-results-2026-09-17.json` | Reported test and offline-evaluation results with an explicit date |
| Protocols | `PERFORMANCE_PROTOCOL.md`, `RECOMMENDATION_EVALUATION_REPORT.md` | How a measured result was produced |
| Published product lists | `catalogue-audit-2026-09-19/`, `barcode-testing-reference-2026-09-21/` | The 91 published products and their barcodes |

`catalogue-audit-2026-09-19/` and `barcode-testing-reference-2026-09-21/`
list the 91 published products and their barcodes.
